# Fuentes de referencia

Estos archivos se usan para:

- Generar el wordmark y los textos convertidos a trazados de los SVG.
- Renderizar `examples/preview.html` sin conexión.
- Producir el Open Graph y los PNG de lockups.

No es necesario copiarlos al frontend: Next los carga con `next/font/google`.
